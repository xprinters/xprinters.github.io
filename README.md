# Сайт поддержки Xprinter

Драйверы, программы и видеоинструкции для термопринтеров Xprinter / 4BARCODE.
Сайт собирается из markdown-файлов с помощью [MkDocs Material](https://squidfunk.github.io/mkdocs-material/)
и публикуется на GitHub Pages. Сами файлы драйверов лежат в Облаке Mail.ru, на сайте только ссылки на них.

## Как устроено

```
mkdocs.yml              — настройки сайта и меню
docs/index.md           — главная
docs/<модель>/index.md  — страница модели, адрес сайта/<модель>/
docs/assets/models/     — фото моделей
docs/guides/            — общие гайды и частые проблемы
docs/support.md         — контакты
snippets/               — общие блоки: приложения (apps.md) и «Не получилось?» (help.md)
hooks/models.py         — ссылки cloud: и карточки моделей на главной
tools/                  — проверка ссылок на облако
```

## Добавить новую модель

1. Скопируйте папку похожей модели, например `docs/v3` → `docs/v5`.
2. В шапке `docs/v5/index.md` поменяйте `title`, `model.name`, `model.order`,
   `model.image`, `model.interfaces` и `cloud` — ссылку на папку модели в Облаке.
3. Положите фото в `docs/assets/models/v5.png`.
4. Добавьте строку в раздел `nav` в `mkdocs.yml`.

Карточка модели на главной появится сама.

## Ссылки на облако

Внутри страницы модели пишите путь от её папки в Облаке:

```markdown
[Скачать](cloud:Драйвер/Windows)
[Видео](<cloud:Драйвер/Windows/Переустановка (полная).mp4>)   ← в угловых скобках, если есть пробелы или скобки
[Чужая папка](cloud:/Kfzk/HHA7de4t3/Инструкции)               ← путь со слеша — от корня публичных ссылок
```

Если папку в облаке переименовали или перенесли, достаточно поправить путь здесь.

## Запустить локально

```bash
pip install -r requirements.txt
mkdocs serve
```

Сайт откроется на http://127.0.0.1:8000 и будет обновляться при сохранении файлов.

Проверка, что все ссылки на облако живые:

```bash
mkdocs build && python tools/check_cloud_links.py
```

## Публикация на GitHub Pages

1. Создайте на GitHub репозиторий и загрузите в него эту папку.
   Если назвать репозиторий `<аккаунт>.github.io`, сайт откроется по адресу `https://<аккаунт>.github.io/`.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. После каждого изменения в ветке `main` сайт пересобирается сам (около минуты), см. вкладку **Actions**.

Править тексты можно прямо на github.com: откройте файл, нажмите карандаш, сохраните.

### Свой домен

1. В `mkdocs.yml` раскомментируйте `site_url` и впишите адрес.
2. Создайте файл `docs/CNAME` с одной строкой — доменом, например `xprinter.help`.
3. У регистратора домена добавьте DNS-записи для GitHub Pages
   (A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`)
   и укажите домен в **Settings → Pages → Custom domain**, включите **Enforce HTTPS**.
