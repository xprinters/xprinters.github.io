!!! info "Драйвер — как у A4PRO"
    Драйвер для компьютера общий с [Xprinter A4PRO](../a4pro/index.md). В списке установщика модели P84 нет — выбирайте **P83**.

## Драйвер

=== ":fontawesome-brands-windows: Windows"

    Драйвер **Xlife 2025.06** (в папке есть и предыдущая версия 2024.05).

    [Скачать для Windows](cloud:Windows){ .md-button .md-button--primary }

=== ":fontawesome-brands-apple: macOS"

    Драйвер `prt.xlife.drv_3.13.16`.

    [Скачать для macOS](cloud:MacOS){ .md-button .md-button--primary }

## Приложение для телефона

Приложение **TattooGo**. Подключайтесь к принтеру из приложения, а не в настройках Bluetooth. Подробнее — в [частых проблемах](../faq/tattoo.md#приложение-для-телефона).
