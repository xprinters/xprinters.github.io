# Первый запуск

Пять шагов из комплектной инструкции — от коробки до первой этикетки. PDF инструкции и видео есть на [странице вашей модели](../models/index.md).

## 1. Подключите питание

1. Убедитесь, что принтер выключен (кнопка питания в положении OFF / O).
2. Вставьте штекер блока питания в разъём питания принтера.
3. Сетевой провод вставьте в блок питания, вилку — в розетку.

USB-кабель только передаёт данные, без блока питания принтер не работает. Разъём RJ-12 рядом с USB — для денежного ящика, к компьютеру его не подключают.

## 2. Вставьте рулон

=== "XP-365B, V2, V3"

    1. Наденьте рулон на держатель, ограничитель — справа.
    2. Положите в отсек так, чтобы лента сходила **с рулона снизу, этикетками вниз**.
    3. Пропустите ленту через **левую зелёную направляющую**, правый бегунок сдвиньте к ленте — не слишком плотно.
    4. Вытяните ленту за корпус примерно на 1 см и закройте крышку.

    Калибровка **автоматическая** — при включении принтер сам прогонит ленту. Лишнюю этикетку верните кнопкой **PAUSE**.

=== "V4"

    1. Наденьте рулон на держатель, ограничители — по бокам, рулон по центру.
    2. Откройте крышку (потяните на себя боковые кнопки) и положите держатель в принтер так, чтобы лента сходила **с рулона сверху**.
    3. Пропустите ленту через направляющие, сдвиньте их к краям ленты, закройте крышку.
    4. **Калибровка:** зажмите кнопку на крышке, включите принтер, отпустите кнопку по звуковому сигналу.

=== "V1BT, Mini"

    1. Откройте крышку, зажав кнопку открытия.
    2. Заведите ленту **сзади**, через отсек подачи, **этикеткой вверх**.
    3. Сдвиньте направляющие к краям ленты и закройте крышку до щелчка.
    4. **Калибровка:** зажмите кнопку FEED на крышке, включите принтер, отпустите кнопку по звуковому сигналу. Повторяйте после каждой смены ленты.

Подробнее и с решением проблем — [Как правильно вставить рулон](../faq/paper.md#как-правильно-вставить-рулон).

## 3. Установите драйвер

1. Скачайте драйвер со [страницы своей модели](../models/index.md).
2. Запустите установщик. Когда он начнёт искать принтер по USB, подключите принтер к компьютеру и **включите** его.
3. Установщик сам найдёт принтер — жмите «Далее» до конца.

| Модель | Как принтер называется в установщике |
|---|---|
| XP-365B | Xprinter XP-365B |
| V2 | 4BARCODE 3B-T371U или 3B-Q371U |
| V3 | 4BARCODE 3B-Q361U |
| V4 | 4BARCODE 4B-2064C |
| V1BT | 4BARCODE 4B-2083B |
| Mini | 4BARCODE 4B-2054N |

По Bluetooth компьютер подключают тоже **через установщик**: тип подключения «Bluetooth» → «Мастер добавления устройства…» → `Printer001` (или имя модели) → PIN **0000**. Подробно — [Bluetooth на компьютере Windows](../faq/phone.md#bluetooth-на-компьютере-windows).

## 4. Задайте размер этикетки

1. Нажмите <kbd>Win</kbd>+<kbd>S</kbd>, найдите **«Принтеры и сканеры»**.
2. Выберите свой принтер → **«Настройка печати»**.
3. Вкладка **«Параметры страницы»** → **«Новая»**.
4. Имя — например `58x40`, ширина и высота этикетки в мм → «ОК».
5. Вкладка **«Графика»** → **«Нет»** (иначе штрихкоды печатаются волнами).
6. **«Применить»** и «ОК».

Подробнее — [Размер этикетки и печать PDF](../faq/size.md).

## 5. Напечатайте первую этикетку

- **Готовые этикетки Ozon, Wildberries:** откройте PDF в **Google Chrome** → <kbd>Ctrl</kbd>+<kbd>P</kbd> → свой принтер, свой размер, масштаб **«По размеру бумаги»**.
- **Свои этикетки:** [редактор этикеток](../editor/index.md) на этом сайте или BarTender UltraLite со страницы модели.
- **С телефона:** приложение **4Barcode**, PIN **0000** — см. [Печать с телефона](phone.md).

Не получилось — смотрите [Частые проблемы](../faq/index.md) или напишите в [поддержку](../support.md).
