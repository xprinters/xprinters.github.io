# Частые проблемы

??? question "Принтер печатает пустые этикетки"

    - Проверьте, что этикетки **термические**: проведите ногтем по этикетке, на ней должен остаться тёмный след.
    - Рулон должен стоять **печатной стороной к печатающей головке**. Переверните рулон и попробуйте снова.
    - В настройках драйвера выберите способ печати **«Прямая термопечать» (Direct Thermal)**, а не «Термотрансфер».

??? question "Печать сдвигается или выходит на две этикетки"

    - Размер бумаги в драйвере или программе должен **точно совпадать** с размером этикетки, например 58×40 мм.
    - Выполните **калибровку**, чтобы принтер заново определил промежутки между этикетками. Пример есть в видео на странице [Xprinter V4](../v4/index.md#видеоинструкции).
    - Тип носителя в драйвере: **этикетки с промежутками (gap)**.

??? question "Этикетка с маркетплейса печатается мелко или обрезается"

    - Создайте в драйвере размер бумаги, который совпадает с этикеткой маркетплейса.
    - При печати PDF выберите масштаб **«Фактический размер»** (100%), а не «Подогнать».

??? question "Компьютер не видит принтер"

    - Подключите принтер другим USB-кабелем или к другому порту, без переходников и USB-хабов.
    - Переустановите драйвер. Видео «Переустановка драйвера» есть на странице вашей модели.
    - В свойствах принтера в Windows на вкладке «Порты» должен быть выбран порт `USB00x`, к которому подключён принтер.

??? question "Не получается подключиться по Bluetooth"

    - Проверьте, что ваша модель с Bluetooth: у моделей есть версии «USB» и «USB + Bluetooth».
    - На Android дайте приложению доступ к Bluetooth и геолокации: без него поиск устройств может не работать.
    - Для Windows смотрите видео «Bluetooth» на странице модели.
