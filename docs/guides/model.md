# Как узнать модель принтера

1. **Наклейка на дне принтера.** Переверните принтер: на наклейке указаны модель и серийный номер.
2. **Коробка или инструкция** из комплекта.
3. **Заказ на маркетплейсе.** В карточке товара в истории заказов Ozon, Wildberries или Мегамаркета.
4. **Сравните с фото.** Все модели с фотографиями — на странице [Принтеры](../models/index.md).

## Заводские названия моделей

На наклейке, в драйвере и в списке Bluetooth модель может называться иначе, чем в магазине:

| В магазине | На наклейке, в драйвере |
|---|---|
| Xprinter XP-365B | XP-365B |
| Xprinter V2 | XP-Q371U, 4BARCODE 3B-T371U / 3B-Q371U |
| Xprinter V3 | XP-Q361U, 4BARCODE 3B-Q361U / 3B-T361U |
| Xprinter V1BT | 4BARCODE 4B-2083B |
| Xprinter V4 | 4BARCODE 4B-2064C |
| Xprinter Mini | 4BARCODE 4B-2054N |
| Xprinter Pocket | XP-P322B |
| A4PRO / A4 Tattoo | Xlife P83 / P84 |

На этой же наклейке в строке «Интерфейс» видно, есть ли у принтера Bluetooth.

Если модель всё равно не понятна, пришлите фото принтера и наклейки в [техподдержку](../support.md).
