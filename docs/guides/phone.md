# Печать с телефона

Печатать с телефона можно на принтерах **с Bluetooth**. Установите приложение 4BarCode:

--8<-- "apps.md"

## Как начать

1. Включите принтер и Bluetooth на телефоне.
2. Откройте 4BarCode и найдите принтер в списке устройств.
3. Создайте этикетку или выберите шаблон и укажите её размер — он должен совпадать с этикетками в принтере.
4. Нажмите «Печать».

Видео по работе с приложением есть на странице каждой модели в разделе «Видеоинструкции».
