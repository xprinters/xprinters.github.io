# macOS

## Как подключить принтер к Mac

На Mac принтер работает **по USB**. Если у MacBook только порты Type-C, нужен переходник USB → Type-C (в комплект не входит).

1. Скачайте драйвер для macOS со [страницы своей модели](../models/index.md) — файл `.pkg`.
2. Установите его: **правой кнопкой** (двумя пальцами по тачпаду) по файлу → «Открыть с помощью» → «Установщик». Если macOS пишет, что разработчик не проверен — разрешите установку в «Системные настройки» → «Конфиденциальность и безопасность».
3. Если установщик просит имя и пароль — это **имя пользователя и пароль от Mac**, а не Apple ID.
4. Подключите и включите принтер. «Системные настройки» → «Принтеры и сканеры» → **«+»** → выберите принтер.
5. В поле «Использовать» → **«Выбрать ПО»** → найдите свою модель: `XP-365B` для Xprinter XP-365B, `4BARCODE 3B-…` / `4B-…` для V-серии (как в [таблице моделей](install.md#нельзя-задать-ширину-больше-5660-мм)).

Драйвер для macOS — это дополнение к системе печати, а не программа: после установки отдельной иконки не появится.

## Как настроить размер этикетки на Mac

1. Откройте любой PDF во встроенной программе **«Просмотр»** (не в браузере).
2. <kbd>Cmd</kbd>+<kbd>P</kbd> → выберите принтер → «Размер бумаги» → **«Управление размерами»**.
3. Нажмите «+», укажите ширину и высоту в **миллиметрах** (58 × 40), поля 0. Проверьте единицы: если ввести 58 дюймов, этикетки будут пустыми.
4. Теперь этот размер можно выбирать в любой программе. После создания размера перезапустите браузер.

Готовые PDF печатайте из Chrome: размер — созданный, масштаб «По размеру бумаги». Если обрезает — попробуйте «Заполнить полностью». Ориентацию на Mac подбирайте по результату.

## Можно ли подключить по Bluetooth

Официально — **нет**. macOS определяет Bluetooth-принтер как аудиоустройство, и драйвер его не видит. Так же ведут себя термопринтеры других марок.

- Печатайте по USB.
- По Bluetooth можно с телефона или с Windows.
- Есть **экспериментальный способ** печати по Bluetooth из браузера Chrome через расширение — [видеоинструкция](https://www.youtube.com/watch?v=zY6LpxCoGWM). Работает не у всех.

## Программа для этикеток на Mac

BarTender существует только для Windows, файлы `.btw` на Mac не открываются. Для своих этикеток на Mac:

- **4Barcode** — веб-версия [4barcode.top](https://www.4barcode.top) в браузере (макеты синхронизируются с телефоном под одним аккаунтом) или приложение из App Store;
- готовые PDF из кабинетов маркетплейсов печатайте из Chrome.

## Принтер «на паузе», «Сбой Backend», печатает одну этикетку

- Удалите принтер в «Принтеры и сканеры» и добавьте заново.
- Переустановите драйвер `.pkg`, перезагрузите Mac.
- Нужна macOS **10.15 Catalina или новее**. На более старых системах появляется ошибка «Backend».
- Проверьте кабель и переходник (например, флешкой).
- Если на Mac два принтера — подключайте по одному и переименовывайте.

## Качество печати на Mac хуже, чем на Windows

Драйвер для Mac проще, в нём нет вкладки «Графика».

- В окне печати откройте параметры принтера: плотность (**Darkness / Density**) уменьшите, если печать жирная; полутона (**Halftone**) попробуйте разные варианты, если серое печатается плохо.
- Разрешение — **203 dpi** (V4 — 300 dpi).
- Для лучшего качества штрихкодов можно печатать с телефона или с Windows.
