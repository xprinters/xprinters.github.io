# Частые проблемы

Ответы собраны из тысяч обращений в нашу техподдержку. Найдите свой случай ниже или нажмите <kbd>/</kbd> и опишите проблему своими словами: «иероглифы», «пустые этикетки», «не видит принтер».

## Быстрые ответы

Больше всего вопросов решают эти пункты:

| Что происходит | Что сделать |
|---|---|
| Печатает **иероглифы** или бесконечную ленту с символами | Принтер в режиме чеков. [Вернуть режим этикеток](paper.md#печатает-иероглифы-символы-или-бесконечную-ленту) |
| Выходят **пустые этикетки** | Рулон стоит не той стороной или этикетки не термо. [Подробнее](paper.md#выходят-пустые-этикетки) |
| **Горит красный и пищит** | Лента не попадает на датчик. [Установить рулон правильно](paper.md#горит-красный-индикатор-и-принтер-пищит) |
| Печатает **на двух этикетках**, боком, мелко | Не настроен размер этикетки в драйвере. [Настроить размер](size.md#как-настроить-размер-этикетки-в-windows) |
| PDF с маркетплейса печатается криво | Печатайте через Chrome, масштаб «По размеру бумаги». [Подробнее](size.md#как-печатать-этикетки-ozon-wb-яндекс-маркет-pdf) |
| Установщик драйвера **не находит принтер** | [Проверить и переустановить драйвер](install.md#установщик-не-находит-принтер) |
| Вместо печати **предлагает сохранить файл** | [Полная переустановка драйвера](install.md#полная-переустановка-драйвера) |
| Телефон **не видит принтер** | Подключайтесь из приложения 4Barcode, а не из настроек Bluetooth. [Подробнее](phone.md#телефон-не-видит-принтер) |
| Штрихкод печатается **волнами**, зигзагом | В драйвере «Графика» → «Нет». [Подробнее](quality.md#штрихкод-печатается-волнами-зигзагом-или-точками) |
| Белая **полоса** на этикетке | Почистите термоголовку. [Как чистить](quality.md#белая-полоса-или-не-пропечатывается-часть-этикетки) |
| **Зажёвывает** ленту при включении | Рулон слишком большой. [Какие рулоны подходят](paper.md#зажёвывает-ленту-рулон-не-помещается) |
| BarTender **просит ключ** или пишет «30 дней» | Выберите редакцию UltraLite. [Подробнее](bartender.md#просит-ключ-пробный-период-30-дней-демо-режим) |
