# Чеки, 1С и другие программы

## Можно ли печатать чеки на кассовой ленте

Да, у XP-365B, V2 и V3 есть **режим чеков (RECEIPT)**. У V4 и Mini его нет.

1. Переключите принтер в режим чеков: выключите, зажмите **PAUSE**, включите, дождитесь `Current mode: LABEL`, один раз нажмите **FEED** → `Current mode: RECEIPT`, выключите и включите. (Обратно — так же, см. [Бумага, калибровка, режимы](paper.md#печатает-иероглифы-символы-или-бесконечную-ленту).)
2. Установите **отдельный драйвер для чеков** («Для кассовых программ» на [странице XP-365B](../xp-365b/index.md)). При установке выберите `XP-58` или `XP-80` по ширине ленты; буква `C` в названии — для принтеров с отрезчиком, у наших его нет.
3. Ленту ставьте без держателя рулона.

В режиме чеков печатают **только кассовые программы** (1С:Касса, МойСклад и т. п.). Из Word, PDF и браузера на кассовую ленту получатся иероглифы.

С телефона чек можно напечатать в 4Barcode: «Печать чека».

## Как подключить к 1С

У 1С свои платные драйверы для принтеров этикеток. Рабочий способ без покупки:

1. Установите обычный драйвер принтера. В «Свойствах принтера» → «Порты» запомните порт (например, `USB001`).
2. Установите драйвер **Proton TTP-4306** на тот же порт (архив пришлёт [поддержка](../support.md)).
3. В 1С: «РМК и подключаемое оборудование» → «Подключаемое оборудование» → «Принтеры этикеток» → «Создать» → драйвер **«Гексагон»**.

Размер этикетки должен совпадать в 1С и в драйвере. Если тестовый PDF из Chrome печатается ровно, а из 1С — нет, дело в шаблоне 1С. Остальные вопросы по 1С — в поддержку 1С.

## МойСклад, Эвотор, АТОЛ, iiko и другие программы

Мы не можем проверить платные и закрытые системы, поэтому по их настройке обращайтесь в их поддержку. Что важно знать:

- для этикеток принтер должен быть в режиме **LABEL**, размер этикетки в программе и в драйвере — одинаковый;
- для чеков — режим **RECEIPT** и драйвер `XP-80` / `XP-58`;
- Эвотор использует свои драйверы по подписке;
- принтер понимает команды **TSPL** (режим этикеток) и **ESC/POS** (режим чеков). Документация для разработчиков — на сайте производителя [xprintertech.com](https://www.xprintertech.com).

## Linux

Драйвер для Linux есть на [странице XP-365B](../xp-365b/index.md) (вкладка Linux) — отдельно для этикеток и для чековой ленты.

1. Удалите ранее добавленные принтеры Xprinter.
2. В папке с драйвером откройте терминал и выполните:
   ```bash
   sudo chmod +x xprinter
   sudo ./xprinter
   ```
   Для моделей 4BARCODE файл может называться `4BARCODE`.
3. Добавьте принтер в системе печати (CUPS, адрес `http://127.0.0.1:631`) и создайте размер этикетки.

Если установщик не находит принтер — обновите систему (`sudo apt update && sudo apt upgrade`) и перезагрузитесь.

## Принтер в сети (Wi-Fi, LAN)

Обычные версии принтеров подключаются по **USB** и **Bluetooth**. Разъём рядом с USB — RJ-12 для денежного ящика, это не сетевой порт.

Для версий XP-365B и V2 с сетевым портом (LAN) инструкция и утилита настройки — на [странице XP-365B](../xp-365b/index.md#документация). Чтобы печатать с нескольких компьютеров на обычной версии, откройте общий доступ к принтеру в Windows.
